# ☀️ Погодка — погода для iPhone и iPad

Бесплатное веб-приложение погоды с живой анимированной сценой. Ставится на экран «Домой» iPhone или iPad и работает как обычное приложение: без App Store, без подписок и без сервера.

**Открыть:** https://unknown-intr.github.io/free_wetaher_iphone/

---

## Что умеет

- **Погода сейчас.** Температура и «ощущается как», влажность, ветер (скорость, направление, порывы), осадки (мм, снег в см, вероятность), давление в мм рт. ст., облачность, УФ-индекс, восход, закат и долгота дня.
- **Прогноз.** По часам на сутки вперёд и на 7 дней: минимум и максимум, осадки, ветер и порывы.
- **Предупреждения о непогоде.** Сильный и ураганный ветер, обильный дождь и снег, жара, мороз, гроза, град, ледяной дождь и гололёд, туман, высокий УФ, высокое и низкое давление, резкий перепад давления. Опасное явление сначала занимает весь экран, потом сворачивается в значок в углу и время от времени о себе напоминает.
- **Этот день в истории.** Любой день календаря за последние 30 лет: максимум и минимум по годам, рекорды тепла и холода, как часто шли осадки и снег, сильнейший порыв, тренд температуры за 10 лет, график и таблица по годам.
- **Что надеть.** Совет по верхней одежде по ощущаемой температуре, осадкам, ветру и УФ. Если ветер сильный, зонт не советуется. Есть сравнение с климатической нормой: «сегодня на 5° теплее обычного».
- **Несколько мест.** Первый экран показывает погоду по геопозиции, остальные города добавляются через поиск. Между ними листаете свайпом.
- **Живая сцена в реалистичном стиле.** Сцена как снимок камерой с малой глубиной резкости: небо, облака, холмы в дымке и дерево мягко размыты, осадки и листья почти резкие, капли на «стекле» — резкие. Небо меняется по времени суток и облачности, Луна — в настоящей фазе. Холм и дерево меняются по сезону. Ветер гнёт дерево и несёт листья, одуванчиковый пух, лепестки или снежинки. Дождь разбивается брызгами о землю, капли стекают по стеклу, у объектива проплывают размытые снежинки, в грозу бьют молнии. Вертушка на флюгере крутится тем быстрее, чем сильнее ветер. Температура при загрузке отсчитывает от −100° до текущей.

## Как установить на iPhone или iPad

1. Откройте ссылку выше в **Safari**. В других браузерах на iPhone нужного пункта может не быть.
2. Нажмите **«Поделиться»** (квадрат со стрелкой вверх) и выберите **«На экран „Домой“»**, затем **«Добавить»**.
3. Запускайте с иконки «Погодка» и разрешите доступ к геопозиции.

Чтобы поставить родным, просто отправьте им ссылку.

Если геопозицию нечаянно запретили, её можно включить в **Настройки → Конфиденциальность и безопасность → Службы геолокации**. Или добавьте город вручную кнопкой ☰.

## Как это работает

```
iPhone ──► GitHub Pages   файлы приложения (кэшируются на телефоне)
iPhone ──► Open-Meteo     погода — напрямую, при каждом открытии
```

- Своего сервера нет. Приложение — это статические файлы на GitHub Pages, а погоду телефон запрашивает напрямую у Open-Meteo. Ничего держать включённым не нужно.
- Список городов и последний прогноз хранятся на самом телефоне, поэтому без интернета видны последние данные с пометкой «Нет связи».
- Новая версия, загруженная в этот репозиторий, приходит на телефоны при следующем запуске.

## Источники данных

| Что | Откуда |
|---|---|
| Прогноз и текущая погода | [Open-Meteo](https://open-meteo.com) Forecast API: модели ECMWF, DWD ICON, GFS и др. |
| Архив за 30 лет | Open-Meteo Historical API, реанализ **ERA5** (Copernicus/ECMWF) |
| Поиск городов | Open-Meteo Geocoding API |
| Название места по геопозиции | [BigDataCloud](https://www.bigdatacloud.com) (бесплатный клиентский API) |

Данные о погоде: © Open-Meteo.com, лицензия [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Использование бесплатно для некоммерческих целей, без ключа и регистрации.

**Конфиденциальность.** Приложение ничего не собирает и никуда не отправляет, кроме координат точки прогноза в Open-Meteo и BigDataCloud. Аккаунтов, рекламы и аналитики нет.

## Ограничения

- **Предупреждения рассчитывает само приложение** по прогнозу, с порогами, близкими к критериям Росгидромета. Это не официальные предупреждения МЧС: бесплатного открытого источника для них нет.
- **Архив — это реанализ ERA5,** то есть восстановленная по наблюдениям станций, спутников и зондов картина на сетке ~10–25 км, а не показания одной метеостанции.
- **Размер градин** бесплатные сервисы не прогнозируют, показывается только «гроза с градом».
- **Давление** крупно показывается на высоте местности, как у Яндекса и Гисметео: в Москве норма около 745 мм. Мелко рядом стоит давление, приведённое к уровню моря (норма 760). Предупреждения о давлении считаются по второму значению.
- **Вибрации при предупреждении нет:** Safari на iPhone её не поддерживает.

## Демо-режим

Проверить анимации осадков можно без нужной погоды: добавьте к адресу параметр.

- `?demo=rain` — дождь
- `?demo=snow` — снег
- `?demo=hail` — град
- `?demo=storm` — гроза
- `?demo=sleet` — ледяной дождь

Во всех режимах заодно включается предупреждение «Ураганный ветер». Пример: https://unknown-intr.github.io/free_wetaher_iphone/web/?demo=snow

## Структура

```
index.html               перенаправление на web/
web/
├── index.html           разметка
├── manifest.webmanifest описание приложения для экрана «Домой»
├── sw.js                офлайн-кэш файлов приложения
├── css/style.css        оформление
├── icons/               иконки
└── js/
    ├── app.js           интерфейс: страницы, карточки, листы, предупреждения
    ├── api.js           запросы к Open-Meteo и кэш
    ├── logic.js         логика: коды погоды, предупреждения, одежда, статистика истории
    └── scene.js         анимированная сцена и флюгер (Canvas)
```

Сборка не нужна: обычные HTML, CSS и JavaScript-модули без библиотек.

Запустить локально:

```bash
cd web && python3 -m http.server 8000
```

Затем откройте http://localhost:8000.

Пороги предупреждений настраиваются в `web/js/logic.js`, объект `THRESHOLDS`.
