# Погодка — погода для iPhone и iPad

> **Как установить:** см. [INSTALL.md](INSTALL.md). Там два варианта: веб-приложение (бесплатно и навсегда) и отдельное приложение (Xcode или SideStore).

Личное приложение для себя и родных: текущая погода с живой анимированной сценой, прогноз на 7 дней,
предупреждения о непогоде, архив за 30 лет и советы, что надеть.

## Что умеет

| Функция | Как сделано |
|---|---|
| Погода сейчас | Температура, ощущается как, влажность, ветер (скорость, направление, порывы), осадки (мм, снег в см, вероятность), давление в мм рт. ст., облачность, УФ, восход, закат и долгота дня |
| Прогноз на неделю | 7 дней: мин/макс, осадки, ветер и порывы, вероятность осадков, плюс почасовой прогноз на сутки |
| Предупреждения | Приложение само считает их по прогнозу: сильный и ураганный ветер, обильный дождь и снег, жара, мороз, гроза, град, ледяной дождь и гололёд, туман, высокий УФ, высокое и низкое давление, резкий перепад давления. Пороги близки к критериям Росгидромета (файл `Pogodka/Logic/AlertEngine.swift`, структура `AlertThresholds`) |
| История за 30 лет | Любой день календаря по каждому году: макс/мин, осадки, снег, порывы, давление, влажность. Ещё есть средние значения, рекорды, доля дождливых лет, тренд температуры за 10 лет и график |
| Что надеть | Совет по ощущаемой температуре, осадкам, ветру (при сильном ветре зонт не советуется), УФ и перепаду день/ночь. Плюс сравнение с климатической нормой: «сегодня на 5° теплее обычного» |
| Места | Первый экран показывает погоду по геопозиции. Другие города добавляются через поиск (кнопка ☰), между экранами листаете свайпом влево и вправо |

### Анимированный экран
- Небо меняется по времени суток (утро, день, вечер, ночь со звёздами и луной) и по облачности.
- Холм и дерево меняются по сезону: весной цветы и лепестки, летом зелень и одуванчиковые парашютики, осенью жёлтые листья, зимой голые ветки и снег.
- Дождь идёт косыми струями, по «стеклу» стекают капли с дорожками. Град падает и отскакивает от земли, снежинки кружатся. В грозу бывают вспышки и молнии, в тумане ползут полосы тумана.
- Ветер сносит частицы и раскачивает дерево. Порывы видны как рывки.
- Флюгер: стрелка показывает, откуда дует ветер, и покачивается, а вертушка крутится тем быстрее, чем сильнее ветер.
- Температура при загрузке отсчитывает от −100° и плавно тормозит у текущего значения.
- Если в ближайшие 3 дня ожидается опасное явление, экран вспыхивает: пульсирующая рамка, крупная иконка, вибрация. Через 6 секунд или по нажатию предупреждение «улетает» в значок в правом верхнем углу. Значок раз в 25 секунд покачивается и пускает кольцо. Нажатие на него открывает список всех предупреждений.

## Откуда данные

[Open-Meteo](https://open-meteo.com): бесплатно, без ключа и регистрации, для некоммерческого использования.
- прогноз: модели ECMWF, DWD ICON, GFS и др. (сервер выбирает лучшую для точки);
- архив: реанализ ERA5 (Copernicus/ECMWF) с 1940 года. Это не показания конкретной метеостанции, а восстановленная по всем наблюдениям картина на сетке ~10–25 км. Для «как обычно бывает в этот день» это надёжный и стандартный источник;
- поиск городов: geocoding Open-Meteo (на русском).

Ответы кэшируются: без интернета показывается последний прогноз с пометкой «нет связи», архив хранится 30 дней.

## Ограничения

- **Официальные штормовые предупреждения МЧС и Росгидромета** через бесплатное API получить нельзя. Apple WeatherKit их отдаёт, но требует платного аккаунта разработчика ($99 в год). Поэтому предупреждения рассчитываются по прогнозу.
- **Размер градин** не прогнозирует ни один бесплатный сервис, приложение сообщает только «гроза с градом».
- **Давление.** Крупно показывается давление на высоте местности, как у Яндекса и Гисметео: в Москве норма около 745 мм. Рядом мелко написано давление, приведённое к уровню моря (норма 760). Предупреждения считаются по второму значению.

## Как установить на свой iPhone или iPad (бесплатно)

Нужны Mac с Xcode (уже установлен), кабель USB и Apple ID (тот же, что в App Store).

### 1. Добавьте Apple ID в Xcode (один раз)
1. Откройте **Xcode → Settings… (⌘,) → Accounts**.
2. Нажмите **+** внизу слева, выберите **Apple ID** и войдите.
3. В списке появится команда «*Ваше Имя* (Personal Team)».

### 2. Откройте проект и выберите подпись
1. Дважды щёлкните `Pogodka.xcodeproj` в папке проекта.
2. Слева выберите синюю иконку **Pogodka**, затем в центре цель **Pogodka** и вкладку **Signing & Capabilities**.
3. Галочка **Automatically manage signing** должна стоять. В поле **Team** выберите «*Ваше Имя* (Personal Team)».
4. Если Xcode пишет, что Bundle Identifier занят, замените `com.unknowner.pogodka` на любой свой уникальный, например `com.ivanov.pogodka`.

### 3. Подготовьте iPhone (один раз)
1. Подключите iPhone к Mac кабелем, разблокируйте его и нажмите **«Доверять этому компьютеру»**.
2. На iPhone откройте **Настройки → Конфиденциальность и безопасность → Режим разработчика** и включите его. Телефон перезагрузится, после перезагрузки подтвердите включение.
   (Пункт появляется, только когда iPhone подключён к Mac с открытым Xcode.)

### 4. Установите
1. Вверху Xcode, рядом с названием «Pogodka», выберите в списке устройств **свой iPhone**.
2. Нажмите **▶ Run** (⌘R). Первая сборка занимает 1–2 минуты.
3. При первом запуске iPhone скажет «Ненадёжный разработчик». Откройте **Настройки → Основные → VPN и управление устройством**, выберите свой Apple ID и нажмите **«Доверять»**.
4. Запустите «Погодку» и разрешите доступ к геопозиции.

### 5. iPad и телефоны родных
Повторите шаги 3–4 для каждого устройства: подключить к Mac, выбрать устройство в Xcode, нажать Run.
После первого подключения можно ставить и по Wi-Fi: **Window → Devices and Simulators** → выберите устройство → **Connect via network**.

### Важно: бесплатная подпись действует 7 дней
С бесплатным Apple ID приложение перестаёт запускаться через 7 дней. Чтобы продлить, подключите устройство и снова нажмите **Run** в Xcode. Данные и список городов сохранятся.
Ещё ограничения бесплатного аккаунта: не больше 3 таких приложений на одном устройстве.

Как обойтись без еженедельного продления:
- **Apple Developer Program** ($99 в год). Сборка работает год, а через **TestFlight** можно разослать приложение родным по ссылке, без кабеля и без их Mac.
- **AltStore / SideStore** (бесплатно) сами продлевают подпись по Wi-Fi раз в неделю.

## Для разработки

```bash
# тесты (Swift Testing, 40+ проверок: разбор API, предупреждения, одежда, история, хранение мест)
xcodebuild -project Pogodka.xcodeproj -scheme Pogodka -destination 'platform=iOS Simulator,name=iPhone 17 Pro' test
```

Структура:
- `Pogodka/Services`: Open-Meteo, геопозиция, кэш, список мест;
- `Pogodka/Logic`: расшифровка кодов погоды, сцена, предупреждения, одежда, статистика истории (чистая логика, покрыта тестами);
- `Pogodka/Views/Scene`: анимированная сцена (Canvas + TimelineView), флюгер, счётчик температуры, оверлей предупреждения;
- `Pogodka/Views`: экраны.
